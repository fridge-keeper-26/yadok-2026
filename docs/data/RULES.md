# RULES

> **초안(AI 대행)**: 이 문서의 Sprint 3 개정(「제외」와 「보기 조건」 분리, 2026-11-23)은 사용자가 결정했고(결정표 9개), **문구는 AI 도우미(Aside)가 대신 썼다.** 사용자가 읽고 채택한 뒤 저장한다. Sprint 2 원본은 사용자가 직접 썼고 Aside가 일부 협조했다(다른 주제의 예제 구조, 빈틈을 묻는 질문, 최종 문구 정리, 빈 곳 4군데 제안 채택).


## 0. 처리 순서
읽기 → 이름 정리 → 칸 검사(제외) → 중복 제거 → 보기 조건 → 정렬 → 화면.
한 건이 제외와 중복에 모두 해당하면 먼저 걸린 제외로만 센다. 중복이면서 보기 조건 밖인 건은 중복으로만 센다. 한 건은 정확히 한 곳에만 센다.
요약 줄은 「원천 N건 → 제외 X · 중복 Y → 냉장고 M건(보기 조건 밖 B · 표시 K) · 기준일 · 출처」로 적고, N = X + Y + M, M = B + K다.


## 1. 칸
- 열: 이름, 구입일, 유통기한, 가격, 비고
- 필수: 이름, 유통기한. 나머지는 비어도 된다.
- 날짜 형식은 YYYY-MM-DD이고, 달력에 없는 날짜는 형식 틀림으로 본다.
- 기준일은 화면에서 직접 지정한 날짜로 하고, 지정하지 않으면 여는 날짜(오늘)로 한다. 어느 쪽이든 요약 줄에 「기준일 YYYY-MM-DD」로 적는다.
  손 정답과 AI 결과를 비교할 때는 같은 기준일을 지정해서 비교하고, 그 날짜를 손 정답 표 맨 위에 적는다.
- 요약 줄의 「출처」에는 읽은 데이터 파일 이름과 '합성 데이터'라는 표시를 적는다.
- 「냉장고 실제 건수」(M)는 제외와 중복을 뺀 건수, 곧 보기 조건 밖 B와 표시 K를 합한 값이다. 잘못된 줄(제외)과 같은 건의 나머지 줄(중복)은 세지 않는다.
- 가격과 비고는 판정(제외·중복·보기 조건·정렬)에 쓰지 않고, 있으면 적힌 그대로 화면에 보여 주기만 한다. 가격 형식이 이상해도 제외하지 않는다.


## 2. 중복
- 이름은 다음 순서로 정리한다. 이 정리는 칸 검사(제외)보다 먼저 하며, 공백만 있는 이름은 정리 후 비어 있는 것으로 본다.
  ① 전각 영문·숫자·공백·기호를 반각으로 바꾼다 ② 앞뒤 공백을 지운다 ③ 이름 안의 연속 공백은 하나로 줄인다 ④ 영문은 소문자로 통일한다.
- 정리한 이름과 구입일이 둘 다 같으면 같은 건이다. 구입일이 다르면 이름이 같아도 별도 건이다.
  구입일이 비어 있거나 형식이 틀려 비운 건은 구입일 없음끼리도 같은 건으로 보지 않는다. 중복 판정 대상이 아니라 각각 남는다.
- 같은 건이 여러 개이면 유통기한이 가장 이른 한 건만 남긴다.
  유통기한까지 같으면 원본에서 먼저 나온 행을 남긴다.
- 남기는 줄은 보기 조건보다 먼저 정해진다. 남긴 줄이 보기 조건 밖이면 그 건은 「보기 조건 밖」으로 세고, 같은 건의 나머지 줄은 「중복」이다. 나머지 줄이 범위 안이어도 마찬가지다(의도한 규칙).
- 남지 않은 건은 「중복」으로 접어서 보여 주고, 줄마다 남긴 줄의 원본 줄 번호(화면 표의 「줄」 칸과 같은 번호)를 함께 적는다.


## 3. 정렬
- 유통기한이 이른 순이다.
- 동점이면 정리한 이름의 글자 코드값 순, 그래도 같으면 구입일 이른 순, 그래도 같으면 원본 행 순서다. 구입일이 없는 건은 구입일 순에서 구입일이 있는 건보다 뒤에 둔다.


## 4. 제외 (잘못된 줄. 위에서부터 처음 걸린 사유 하나만 기록)
1. 이름 또는 유통기한이 비어 있음 → 「필수 빠짐」
2. 유통기한 형식이 틀림 → 「형식 틀림」
- 제외된 건은 이유 이름과 함께 접어서 보여 준다.
- 구입일이 있는데 형식이 틀린 건은 제외하지 않는다. 구입일만 비운 것으로 보고, 화면에 「구입일 형식 틀림」 표시를 붙여 남긴다. 이 건은 「표시 K건」에 센다.


## 5. 보기 조건 (제외와 중복을 거친 건에만 적용)
- 유통기한이 기준일보다 10일 넘게 이전이거나 30일 넘게 이후이면 「보기 조건 밖」이다. 잘못된 줄이 아니라 지금은 표에 보여 주지 않을 뿐이며, 냉장고 실제 건수(M)에는 센다.
  기준일에서 10일 전(−10일)과 30일 후(+30일) 당일은 남기고(표시), −11일부터와 +31일부터를 보기 조건 밖으로 본다.
- 보기 조건 밖인 건은 이유 이름 「보기 조건 밖」과 함께 접어서 보여 준다(제외·중복과 같은 방식).
- 보기 조건의 범위(−10일·+30일)는 고정이며 화면에서 바꾸지 않는다.
